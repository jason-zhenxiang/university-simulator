# 大学模拟器 · University Simulator

> 如果大学四年可以重新选择，你会走向怎样的生活？

一款以华南理工大学校园生活为背景的互动文字游戏，也是 **2026 华工新生大数据**的互动体验作品。走进新生集市、拆开一封留给新生的信，再从五扇门中选择自己的方向，在故事与选择中体验大学四年的不同可能。

**[🎮 在线体验](https://jason-zhenxiang.github.io/university-simulator/) · [📖 AIGC 互动小游戏共创指南](https://tcnp9csv9ud9.feishu.cn/wiki/E7LOwi6nwixQsBkRlKlcI2CNnsb)**

## 关于这个项目

大学生活有许多值得尝试的方向：一次实验、一场比赛、一段实习、一趟交流，或者一件坚持了很久的小事。

《大学模拟器》把这些可能写进互动故事。你可以沿着一条路线走到结局，也可以回到入口，看看另一扇门后的生活。成功、挫折、收获与遗憾，都可以成为成长的一部分。

项目将校园叙事、新生统计与彩色拼豆风格的画面结合，希望为即将开始大学生活的你，提供一次轻松的探索。

## 你可以体验什么

- **五条成长路线，15 个分支结局**：选择不同方向，遇见不同的大学经历与成长身份。
- **互动式新生集市**：浏览校区、学院等统计，查询同名、同姓、同生日等新生信息。
- **按自己的节奏阅读**：支持逐句自动播放、暂停、手动推进，以及阶段跳过与剧情回顾；遇到选择时等待你亲自决定。
- **继续未完的故事**：在当前浏览器保存阅读进度和已体验路线，方便下次继续。
- **留下毕业寄语**：回顾走过的路线，写下想说的话，生成并保存属于自己的纪念卡。
- **彩色拼豆视觉**：以校园建筑、角色与道具插画，串起从入学到毕业的旅程。
- **手机优先的网页体验**：支持手机与桌面浏览器，也提供可离线打开的单文件版本。

## 开始体验

### 在线游玩

打开 **[大学模拟器](https://jason-zhenxiang.github.io/university-simulator/)** 即可开始，无需安装应用。

进入新生集市后，你可以先看看新生数据，再跟随故事选择成长路线。完成一条路线后，可以探索其他方向，也可以前往毕业章节，留下寄语并生成纪念卡。

阅读进度保存在当前浏览器中；更换设备、浏览器或清理网站数据后，原有进度不会自动同步。

### 离线游玩

获取项目中的 **`大学模拟器-拼豆版.html`**，使用浏览器打开即可。该文件内嵌脚本、样式、统计数据和图片资源，可独立运行。

## 内容与数据

故事内容由项目剧本整理导入。新生统计以项目中的匿名汇总表为来源，覆盖校区、学院、同名、同姓、生日和星座等信息。

查询结果受原始统计表的收录范围限制，未收录的记录不会被直接当作零人。同名查询中，已收录人数包含本人时，展示的其他同名同学人数会扣除本人。

画面包含 AI 辅助生成的拼豆插画、校园建筑参考及项目提供的素材，具体来源见 [美术来源说明](docs/美术来源.md)。

## 一起创作新的大学故事

本项目也作为 **AIGC 互动小游戏**共创活动的主产品示例。欢迎从真实或可信的大学经历出发，创作新的成长路线。

你可以参考现有的五个方向，也可以提出自己的主题。故事应让玩家拥有有意义的选择，并让不同选择带来不同的经历与结果。

课程共创的交付内容包括故事提案与完整脚本、可点击样稿、视觉与素材包、制作过程报告、测试与修改记录，以及项目管理记录。完整要求与安排见 **[飞书共创指南](https://tcnp9csv9ud9.feishu.cn/wiki/E7LOwi6nwixQsBkRlKlcI2CNnsb)**。

如果你发现剧情、数据或显示问题，欢迎通过仓库 Issue 反馈，并附上复现步骤、设备与浏览器信息。提出新故事或素材建议时，也请注明来源与使用授权。
